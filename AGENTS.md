# SIVIA ModelAtlas

This is the independent MCM/ICM and data-modeling figure project. The adjacent Sivia research checkout is reference context, not this project's write target.

Primary product: reusable drawing skills, a searchable paper-to-figure knowledge base, and executable data-figure rendering with provenance. MCM/ICM is first; CUMCM is a secondary competition profile. Keep task intent, model dependencies and data semantics ahead of styling.

Use AnySearch for literature discovery when available; retain source URLs and distinguish search metadata, read papers and curated figure cards. A paper title or a PDF text import is not an understood case. Do not infer awards from a paper topic.

Quantitative graphics must be computed from supplied data. Generated illustrations may help conceptual scenes but never replace empirical points, coefficients or uncertainty bands. Examples are explicitly demo data. Bundle spec, input snapshot, actual output, audit and hashes. Mechanical audit is not human visual approval.

Keep credentials in the environment or OS credential manager. Ignore local papers and workspace state. Use independent Git history and branches prefixed codex/. Run pytest and the demo render before releasing renderer changes.
