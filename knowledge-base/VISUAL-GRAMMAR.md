# 图里要有模型，而不只是模型名

同一套等宽卡片，不适合所有论文。参考图可以借鉴，也可以有需要避开的缺点。

| 论文关系 | 优先画什么 | 不要用什么代替 |
| --- | --- | --- |
| 物理与生态反馈 | 同一状态、带含义的作用边、反馈返回点 | 图标加圆形箭头 |
| 定位与搜救 | 同一坐标中的位置、搜索范围、更新后的状态 | 各自独立的小地图 |
| 隐变量推断 | 观测记录、约束域、同输入下的比较 | Data → Model → Result 三个框 |
| 经营决策 | 容量、收支项、现金与决策时间 | 球、钱币、奖杯的排列 |
| 政策评价 | 国家×年份记录、组内变化与组间差分 | 机构图标与“政策有效”标签 |

## Sivia 中借什么

已查看 Sivia `1.1.0+codex.20260909060506` 的 TRACE、Reasoning Between Words、EventBridge-RL
成图与完整 prompt。借鉴的是证据对象、前后身份连续性、局部变化和主次比例；不照搬其中的多面板、
语言模型机制或性能指标。这里只保存原创分析，不复制它们的图片或 prompt，也不把生成案例算进 O/F 来源。

完整重画的 prompt 绑定 Sivia overview 模板：15,356 个非空白字符，记录模板版本与 SHA-256。
工具上限为 32,000 个总字符。每次单独检查实际提交文本，不累计历史，不靠重复形容词凑长度。
字数检查之外，还要核对对象、操作数、连线端点和输出图；长 prompt 也可能画错。
