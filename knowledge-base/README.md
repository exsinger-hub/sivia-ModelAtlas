# ModelAtlas 知识库

知识库由两类对象组成：**读过来源的参考卡片**与**实际执行的配对案例**。

`src/modelatlas/knowledge/sources.json` 保存论文/官方题目来源；`cards.json` 保存图表用途、来源定位和使用建议。初始化后写入独立的本地 SQLite。导入 PDF 会记录 SHA-256 与逐页文本，不会自动将未经阅读的片段标成高质量知识。

首轮以 2024 MCM C 题的网球动量为问题锚点，以 Lei 等的 HMM/预测论文、Lv 等的 CatBoost/随机森林论文为绘图阅读材料。已核对论文页面和相关章节；未核验获奖等级，不标成 O 奖论文。数据依赖、时间序列、预测对照和相关矩阵的图式来自对这些材料的阅读；残差、情景敏感性和 Pareto 模板是项目自己的可执行配方。

运行 `python scripts/demo.py` 后，`outputs/demo/` 为每类图保存：图像 PNG、可编辑 SVG、PDF、完整 spec、数据快照、prompt、审查记录和哈希清单。示例数值是明确标记的演示数据，未冒充论文实验。默认不提交本地 PDF 或用户数据。

对新论文的闭环：检索 → 阅读原文及图 → 记录页/节/图定位 → 新建卡片 → 绑定当前任务数据 → 渲染 → 检查 → 修改 → 保存配对案例。阅读任务与作图执行任务可分别进行；只有实际成图才算完成绘图。
