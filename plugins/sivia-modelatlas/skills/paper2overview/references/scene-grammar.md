# Draw the operation, not the heading

The manuscript determines the scientific relation. Retrieved references supply possible visual
techniques, not a compulsory card layout. The source itself may have a weak layout: borrowing is selective.

## Before writing the prompt

1. Name the one transformation the reader must understand. Give it the largest useful area.
2. Pick a carrier that exposes it: state, organism, coordinate field, ledger, row, ranking or constraint.
3. Specify what remains identical before/after and what changes. Reuse identifiers deliberately.
4. Draw at least the core operation inside the carrier, not just an icon and method name.
5. Separate observation, inference, intervention, association and evaluation.

## Paper-specific choices

- Feedback: use a signed physical interaction or state loop, with a named returned state.
- Spatial decision: keep one coordinate frame and update the actual belief/search region.
- Inference: show the constrained domain, output uncertainty and fixed comparison inputs.
- Economics: show capacity, additive/subtractive terms and which state a decision updates.
- Ecology: show typed organism/resource relations and the intervention that changes an edge.
- Policy: show actor × time evidence and the actual contrast; descriptive groups are not treatment groups.

These are alternatives, not an instruction to add all six to one figure.

## Avoid interchangeable modules

Do not begin with equal-width panels, a heading per model and one stock icon per panel. A table's
rules, an axis, a feasible-set boundary and a local bracket have scientific meaning; generic colored
cards usually do not. Use local source labels when global routes become ambiguous. A simpler correct
endpoint is better than an elaborate loop that points at the wrong state.

Keep context subordinate. An arena explains capacity only if seats, demand and the cap are connected.
A policy document explains text analysis only if selected spans become meaningful themes. Remove
unrelated mascots, coin stacks, shields and anonymous node clouds.

## Review the actual image

Hide headings: can the object and operation still be identified? Check each arrow's source and
destination against the paper. Check identities and color semantics across before/after states.
Verify conditional gates, signs, summations, optimization direction and time boundaries. Never turn
symbolic sketches into plausible-looking empirical charts. Look at the full image and a reduced
preview; record a physical-print proof separately if it was not performed.

The inspected Sivia cases contribute persistent identities, concrete intermediate states and selective
change. Their panel count, subject-specific algorithms and metric chips are not standards to copy.
